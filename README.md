# infomercial-nyc

The website for Infomercial, a TV rating and review app for iPhone.

Plain files and nothing to build: `index.html`, `site.css`, `site.js`, the icon
and three fonts. The page loads nothing from anywhere else and keeps nothing
about who visits it.
